# Practical 10 - Implement Kruskal’s algorithm.

## Summary
We implemented Kruskal's Algorithm to find the Minimum Spanning Tree of a weighted graph. The algorithm sorts all edges by weight and selects the minimum-weight edges without forming a cycle.

## Conclusion
Kruskal's Algorithm is a greedy algorithm used to connect all vertices with minimum total cost. It avoids cycles and gives an optimal Minimum Spanning Tree.
