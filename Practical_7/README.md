# Practical 7 - Implementation of change problem using Dynamic programing

## summary
We implemented the Making Change problem using Dynamic Programming and used a DP table to find the minimum number of coins needed for a given amount.
We also measured the execution time and studied the time of the solution.

## Conclusion
Dynamic Programming helps us avoid repeating the same calculations and gives the minimum number of coins efficiently.
The algorithm has O(n × amount) time complexity and O(amount) space complexity, making it suitable for larger amounts.
