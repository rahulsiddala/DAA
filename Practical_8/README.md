# Practical 8 - Implementation of Graph and Searching (DFS and BFS).

## DFS – Summary
We implemented Depth First Search (DFS) to traverse a graph. DFS visits a vertex and then goes as deep as possible before coming back and visiting other vertices. We also measured the execution time and studied its time and space complexity.

## Conclusion
DFS is useful for exploring graphs and finding paths. It uses recursion or a stack and has O(V + E) time complexity, making it efficient for graph traversal.

## BFS – Summary
We implemented Breadth First Search (BFS) to traverse a graph. BFS visits the vertices level by level using a queue. We also measured the execution time and studied its time and space complexity.

## Conclusion
BFS is useful when we need to visit nearby vertices first or find the shortest path in an unweighted graph. It has O(V + E) time complexity and uses a queue for traversal.
