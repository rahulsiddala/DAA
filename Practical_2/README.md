# Practical 2 - Linear Search

## summary
Linear search checks each item one by one, while binary search splits a sorted list and finds the item faster. Use linear search for small or unsorted data, and binary search for large sorted data.

## Conclusion
Linear search and binary search are both used to find an element in a list, but they work in different ways. Linear search checks each element one by one from the beginning, so it is simple and easy to understand. Binary search is faster for sorted data because it repeatedly divides the list into half and eliminates the unnecessary part. In this practical, I learned that linear search is useful for small or unsorted data, while binary search is more efficient for sorted data.
