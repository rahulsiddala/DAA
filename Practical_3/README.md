# Practical 3 - Max Heap sort

## summary
We studied Max Heap and Heap Sort and learned how a heap is built and used to arrange elements in sorted order.
We also checked the execution time and time and space complexity of the algorithm.

## Conclusion
From this experiment, we understood how a Max Heap is created and how Heap Sort uses it to sort the elements.
We also learned that Heap Sort gives O(n log n) performance in the best, average, and worst cases.
It is useful for handling large amounts of data because its performance remains consistent.
