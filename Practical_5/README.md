# Practical 5 - Implementation of a knapsack problem using dynamic programming.

## summary
We studied the 0/1 Knapsack problem and implemented it using Dynamic Programming to select items with maximum value within a given capacity.
We used the weight and value of each item as input and analyzed the time and space requirements of the algorithm.

## Conclusion
The Dynamic Programming approach gives an optimal solution by deciding whether to include or exclude each item.
It has O(n × W) time and space complexity and is useful for solving resource allocation and selection problems efficiently.
